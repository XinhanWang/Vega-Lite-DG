# SVG font redistribution and renderer verification — 2026-11-11

The original 16 fonts remain the base sampling population. 17 added support faces provide real italic/bold-italic variants and Gothic demi; manifest sampling_role distinguishes them. No family substitution or synthetic face is performed. Noto Mono only supports 400 normal. Bookman uses 300/600; Gothic uses 400/600. A requested unsupported face or absent cmap character is rejected with family/weight/style and codepoints.

DejaVu: each notice includes actual name0/name13 from the shipped file, including Bitstream/Arev terms where present. Subsets retain notices in SVG metadata and font name records. Noto Mono: actual name13 declares OFL 1.1; SVG carries the full packaged OFL/copyright notice. name13 declarations alone are not used as a substitute for complete notices. fsType restricted-license, no-subsetting, bitmap-only, and unsupported bits are rejected.

URW/Nimbus: actual OTF name13/name14 are absent, fsType=4. The exact OTF bytes all match Artifex upstream commit 3c0ba3b5687632dfc66526544a4e811fe0ec0cd9. Upstream LICENSE grants AGPLv3 with an exception only for PS/PDF; the exception is not relied on for SVG. Each SVG using URW includes: unmodified full OTF bytes; actual font copyright; complete LICENSE and COPYING; and the complete pinned upstream repository tar.gz as base64 metadata with SHA-256. Helper verifies the embedded OTF against that archive and presence of same-name Type1 .t1, AFM and TTF. The complete upstream source/forms as published accompany each distributed SVG. Extract metadata.source_archives[sha256].base64 using base64 decoding, then unpack gzip tar. No extra network or local fonts are required.

Important scope: upstream publishes Type1/OTF/TTF/AFM but provides no OTF build recipe in this archive. Font hash correspondence is verified; byte-for-byte rebuilding from Type1 is not verified or claimed. This source-bundled implementation is not an absolute legal assurance about source sufficiency or whether a particular combined distribution is an aggregate. Font programs remain AGPL; this helper does not assign a license to separable chart data/text. Preserve all embedded notices and source when redistributing SVG; do not strip metadata from a licensed font-bearing artifact.

URW SVG is approximately 15 MB because complete upstream source is included once per SVG, not because subset processing failed. URW is intentionally unmodified; DejaVu/Noto use fontTools subsets.

Rendering: native resvg 2.6.2 does NOT support fontBuffers in its public native API. Unknown options must not be taken as proof of support. Production extracts font data URIs from SVG, creates a mode 0700 ephemeral directory and mode 0600 font files, loads only those files with loadSystemFonts:false/fontDirs:[], renders and cleans in finally. The stored SVG references only data URIs. A runtime positive/negative probe rejects inability to load isolated temporary fonts. Sharp is explicitly rejected before package resolution. Capability-probe input may read a pinned font; actual chart rasterization reads only bytes embedded in that SVG.

Fingerprint hashes render.mjs, font_embedding.py, fontTools version, every license/source file, all loaded font files and manifest. Changes invalidate resume identity. Canvas layout may remain Vega estimateWidth: embedding does not certify geometry text bboxes; isolated-browser bbox checking is handled by the main agent.

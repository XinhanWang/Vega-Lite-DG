# GT 身份与字段顺序（2026-11-12）

本约定不改变现有图表类型、数值、误差上下界、堆叠段值及连线规则。JSON 对象键顺序是统一序列化规范，不代表数学意义；`data.values` 的行顺序仍具有首次可见顺序和路径/堆叠语义。

## 1. 数据对象

- 柱图：`category → category_id（按需）→ value → lower → upper → path_order → stack_order → start → end → series（如需）→ series_id（按需）`。只保留适用于当前图的原有字段，`path_order` 只适用于折线，不出现在柱图。
- 折线/散点：`x → x_id（仅离散 X 重名时）→ y → 原有区间/顺序字段 → series → series_id`。
- `series` 在所有基础/数值/顺序字段后；`series_id` 紧跟它且始终最后。可选字段省略，不添加空值占位，不改变剩余字段相对次序。单系列无图例省略 `series` 与系列编码。
- 本工具的九类支持范围不扩大。箱线、扇区、雷达、复合/子图等文档中现有类型保留其自己的字段与科学规则；本次不能把它们有损转成柱/线/点。

## 2. 重名与身份

显示文本不修改。**先依据实际类别位置或系列图形建立身份，再检查不同对象是否同名**。一个类别跨多个系列、一条系列跨多个点不是重名对象。

对应维度有不同实际对象同名时，为该维度的全部对象按首次可见顺序编号（包括该维度未重名对象）：

| 显示字段 | 身份字段 | 导出格式 |
|---|---|---|
| 柱图 `category` | `category_id` | 字符串 `C1`, `C2`, ... |
| 离散 X 折线 `x` | `x_id` | 字符串 `X1`, `X2`, ... |
| 图例 `series` | `series_id` | 字符串 `S1`, `S2`, ... |

`x_id` 与 `category_id` 具有相同的“离散位置身份”含义，但保留不同的数据角色：已有点/线仍写 `x`，不能为了统一命名改成 `category`；两列不并存。真正连续数值 X、真实时间坐标不因数值重复而分配离散位置 ID。

同一实际对象所有记录共用 ID；各维度独立判定，无重名维度不导出冗余 ID。无法从历史文件恢复实际身份时明确报错，不能按相同文本猜测、按每行生成身份，或跨系列分别编号类别。

```json
{"category":"Control","value":10,"series":"Experiment A"}
{"category":"2017","category_id":"C1","value":4700}
{"category":"Control","value":10,"series":"Control","series_id":"S1"}
{"category":"Control","category_id":"C1","value":10,"series":"Control","series_id":"S1"}
```

上述是四种独立表结构的单行示意，不应把它们拼成字段不一致的同一张表。编号从 1 开始；字符串没有补零和大小写变体。

## 3. 标注平台

工程中保存类别对象和系列对象的稳定、不透明 `key`；记录通过 `_categoryKey`、`_seriesKey` 绑定对象。名称不作为主键。类别对象按真实轴位置创建；重名系列是独立的系列列表对象，即使颜色或名称相同也不合并。

- 普通操作仍为添加/选择类别位置、添加/选择系列、取点或编辑数据。没有人工 ID 输入。
- 类别名称逐位置编辑；数据表使用带位置序号的选择器区分同名对象。这个序号仅用于 UI，不写回标签。
- 改名只更新绑定对象；上下移动只改变可见顺序；增加记录继续选择已有对象；新增类别/系列产生新稳定 key。
- 删除对象需确认，移除其记录及对应证据；删除单条记录不重建其他对象。撤销、重做及工程备份保留 key。
- `C/X/S` 是每次导出的顺序 ID，可因对象重排、增删或重名消失而更新/省略，不是跨版本永久主键；稳定工程 key 不随之改变。

## 4. GT、Renderer 与兼容

GT 类别通道在需要时绑定 `category_id` / `x_id`；系列的 color、分组 offset 等通道同时绑定 `series_id`。无 ID 时沿用 `category` / `x` / `series`。

Renderer 在深拷贝的 GT 上按 ID 建立显示文本映射，给轴注入 `axis.labelExpr`、给图例注入 `legend.labelExpr`；字符串使用 JSON 转义。GT 不保存这些表达式、映射字典、内部 key、像素证据或显示配置。`compact.preview.vl.json` 是显示副本，不是训练标签。

导入旧 `category_instance`、`x_instance`、`series_instance` 时，先按旧身份列恢复对象，再按新规则重投影；新导出不保留旧列。兼容旧工程 version 1/2；新工程继续使用 version 2，增加可选对象表与稳定引用。历史文件没有任何身份信息且同名实际对象无法区分时，不做有损推断。

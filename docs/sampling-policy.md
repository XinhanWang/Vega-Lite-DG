# 通用多样性采样

原生的 `pipeline.py generate` 和扩展的 `generate_chartarena_extensions.mjs` 都调用同一个确定性规划器。配置省略 `sampling` 时直接使用通用默认值。既有 VSR 数据族、科学量纲、字形选择与有条件的绘图规则继续用于构造数据和图像。历史 VSR 参数代码也保留为回归参照。

`counts` 控制任务数量，`seed` 与图型和样本索引共同生成样本种子。各参数以独立的字段随机流采样。添加一个权重配置不会推进其他随机流。原生和扩展都支持显式的 `controls.all` 与 `controls.<kind>`，后者优先。显式值覆盖相应权重和区间。例如扩展 `controls.radar.radial_max` 可指定确切量程。

`sampling.weighted` 主要用于配置科学任务和子类型。可使用 `all.profile` 统一配置显示风格，按图型配置 `stack_mode`、`x_mode`、`value_mode`、`radar.variant`、`combination.dual_axis` 等。已有合法的权重条目走同一规划器，便于复用存量配置。`zh_probability`、`text_profile` 和 `label_probability` 仍可独立设置。

`sampling.ranges` 使用 `all` 或图型键，字段值为 `[lower, upper]`。整数端点包含在候选中，连续范围的上端点用于确定抽样跨度。相同端点可固定参数。显式控制优先于权重，权重优先于区间。随机数量组合从可行候选中选取。原生低层权重若抽中冲突组合，最多确定性尝试四次。显式参数冲突或无法满足的候选范围会报告原因。

```json
{
  "ranges": {
    "all": {"aspect_ratio": [1.1, 1.9]},
    "radar": {"category_count": [6, 24], "radial_exponent": [-1, 3]},
    "combination": {"category_count": [6, 16]}
  },
  "weighted": {
    "radar": {"variant": [{"value": "line", "weight": 3}, {"value": "filled", "weight": 2}]}
  }
}
```

| 图型 | 默认数量范围及约束 |
| --- | --- |
| 单系列柱图 | 4–24 个类别 |
| 分组柱图、堆叠柱图 | 4–16 个类别，分组 2–5 系列，堆叠 2–6 系列，优先较少系列 |
| 折线 | 单系列 6–30 点，多系列 6–24 点/系列、2–5 系列，覆盖类别、时间标签和连续轴 |
| 散点 | 单系列 12–60 点，多系列 12–48 点、2–5 系列，至少满足 `4 × 系列数 + 4` 个点 |
| 饼图、箱线图 | 2–8 类，饼/环与横/纵分别等权，绝对饼图始终显示精确值 |
| 雷达 | 4–36 维、1–8 系列，偏向较小规模，按维度和子类限制上限 |
| 柱线 | 4–18 类，柱、线各 1–3 系列，偏向较少系列，单/双 Y 默认等权 |

原生图比例连续采样，默认饼图 0.9–1.65、纵向柱图与折线 1.1–2.1、其余 0.95–1.9。雷达 0.9–1.65，柱线 1.25–2.3。比例配置允许 0.6–3。文本布局可按轴标题、类别标签和图例大小扩展最终画布。拥挤的横轴类别标签采用自适应倾角，以保留文字并减少过宽画幅。显式原生 `style.figsize` 直接使用指定大小。

雷达的量程由基数 1、2、2.5 或 5 与 `10^k` 组合，默认 `k=-1…4`。刻度在 3–8 中由可用像素、维度数和量程尾数决定。旋转在 `[-180, 180)` 连续采样，线宽 1–3.2。网格和六种数据模式从合法选项选择。雷达原生子类条件、密度标签限制和叠加恢复规则见 [扩展图表说明](chartarena-scan.md)。

柱线绘图的旋转 −38–0°、折线线宽 1.35–3、柱不透明度 0.74–1 均连续采样。雷达折线与柱线共用点标记和虚线选择策略。月标签可跨年，超过 12 个月时同时显示年份和月份。

Compact GT、数值精度、百分比语义及表格路径沿用既有契约。重新渲染历史样本可沿用已保存的观察配置。采样或投影版本发生变化时，续跑检查会阻止在同一运行目录混入新旧样本。
